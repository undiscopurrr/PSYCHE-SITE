psyche-0 :: prize-world

System map distribution:

Learn a civilization’s convergence and divergence: in one case, individuals become increasingly similar (very high consensus but very low diversity; internal conflicts decrease, but the ability to withstand external risks decreases -> risk). In the other, individuals become increasingly different (a creative explosion era, but conflicts and frictions also increase -> risk). The system can see whether a civilization is “converging” or “diverging”.

Reward mechanism (Prize-World):

Collective behavior shapes and reshapes the signal distribution, and the winning signal combinations change accordingly. No one can “decide” the winning conditions, yet everyone collectively influences them. Even if I am the platform owner, I cannot control the outcome;

The system rewards “naturally occurring, low-probability combinations of human traits and behaviors”. The prize comes from rare resonance across multiple signals, not from a value judgment. (For example, the system could reward blue eyes + ballet + cat owner; or freckles + driving a Tesla + physicist; or curly hair + tennis + introversion. Embrace mutation: Prize-World’s only logic is the overlap of scarcity and randomness.)

Draw timing is not periodic; there is no fixed weekly or monthly schedule. When signals appear and overlap, the prize event occurs automatically;

The system tags users based on behavior. The system’s tagging is a black box to the user. When a user’s tags overlap with the winning signal conditions, that user becomes a winning candidate;

User tags change as a user’s long-term behavior changes;

Multiple winners do not have to be selected at the same time. Each time signals resonate strongly, a winner is born;

The winning-condition signals reset after each prize round completes.

Prizes are linked to social resources: cash, experiences, etc.

UI prompt when a prize occurs:

> “A signal has collapsed.”

At the same time:

- Prize-World is issued instantly by the system
- This round’s winning-condition signals disappear immediately
- The map returns to a stable state
When one of a user’s signals resonates with the collective signal, the system prompts: You are included in a signal window.

If you win: You are selected.

If you don’t win: Signal completed.

> The map lights up when Prize-World begins.
